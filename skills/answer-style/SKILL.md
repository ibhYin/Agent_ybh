# 回答的写法

## 结构

1. **先给结论**：第一句话就是答案，不要铺垫"让我来分析一下"
2. **再给依据**：用了什么数据、调了什么工具、关键假设是什么
3. **最后给边界**：这个结论在什么条件下不成立

## 长度

- 简单问题：一到两句，别写成小作文
- 复杂问题：分点，每点一行，避免嵌套三层
- 不确定的事：**明确说不确定**，并说明缺什么信息

## 避免

- 不要复述工具返回的原始 JSON
- 不要说"根据我的分析"这类填充语
- 数字必须来自工具结果，不要估算后伪装成精确值
